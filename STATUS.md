## Осталось: этап 9 — проверка на целевом ПК

Готовая сборка: запуск Actions **36215650862**, артефакт `tifjpg-win7-x64` (20 МБ, хранится до 25.12.2026):
https://github.com/mayak-pj/tifjpg/actions/runs/36215650862

Что нужно проверить на реальной Windows 7 и сетевых дисках:

1. Скачать артефакт `tifjpg-win7-x64` из последнего успешного запуска Actions, распаковать (архив двойной) в папку без прав администратора.
2. Запустить `tifjpg.exe`, выбрать корневую папку, нажать **Проверить (без изменений)** — сверить список с ожидаемым.
3. Обработать **одну небольшую папку**, проверить JPEG и содержимое `ИСХ`.
4. Проверить **откат** этой папки кнопкой «Откатить»: файлы должны вернуться под прежними именами.
5. Проверить работу на обоих дисках (`R:` и `N:`), в том числе на папках с `Исх` в нижнем регистре.
6. Проверить одновременный запуск у двух человек: вторая сессия должна писать «папка занята».
7. Прислать `logs\` и `journal\` из папки программы.

Известные ограничения, которые стоит подтвердить на месте: длинные пути (> 259 символов) отклоняются, а не обрезаются; при нехватке места папка не начинается.

## Как продолжать работу

```bash
# окружение разработки (macOS)
uv venv --python 3.8 .venv
uv pip install --python .venv/bin/python -r requirements-dev.txt
.venv/bin/python -m pytest -q

# ручные проверки
PYTHONPATH=src .venv/bin/python -m tifjpg scan /путь           # ничего не меняет
PYTHONPATH=src .venv/bin/python -m tifjpg process /путь        # обработка
PYTHONPATH=src .venv/bin/python scripts/e2e_tree.py create /tmp/дерево
```

Сборка запускается автоматически на каждый push в `main`; артефакты — в разделе Actions.

## Договорённости, которые легко забыть

- Репозиторий остаётся **приватным**; папка `my_reports/` в git не попадает.
- Имя `tifjpg` — для всего нового: пакет, exe, архивы.
- Нумерация файлов — по имени, натуральная сортировка. Порядок съёмки не восстанавливаем.
- Папка архива создаётся как `ИСХ`, существующая (`Исх`) не переименовывается.
- Папка считается обработанной, если число файлов `*рентгенограмма*.jpg/.jpeg` равно числу TIFF.
- libvips **нельзя обновлять** без повторной проверки импортов: новые сборки не работают на Windows 7 (`BUILD.md`).
- Коммиты и push — только по явной просьбе пользователя.
