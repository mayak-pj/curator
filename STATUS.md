**Окно теперь можно открыть и локально на Mac**, не только на целевом ПК. Раньше мешала поломка Tcl/Tk в `uv`-окружении (Python не находил свой же `init.tcl` — путь был зашит под другую машину сборки); чинится на время запуска двумя переменными окружения:

```bash

Автоматические скриншоты окна с этой стороны ненадёжны — дважды подряд вместо окна программы в кадр попадало постороннее содержимое экрана (скриншоты в обоих случаях сразу удалены), поэтому визуальная проверка — на пользователе: он смотрит сам и говорит, что видит. Окончательная проверка — всё равно на целевом ПК: там настоящая `vista`, а не её имитация через `clam`.

## Договорённости, которые легко забыть

- Репозиторий **публичный** с 09.10.2026 (решение пользователя, D19); папка `my_reports/` всё равно в git не попадает — это правило не зависело от видимости репозитория и не менялось.
- Имя `curator` — для всего нового: пакет, exe, архивы.
- В `main` `curator.exe` — версия 2 (Qt); версия 1 (tkinter) собирается только в ветке `v1`. Версии 2 без `locks_dir`/`legacy_journal_dirs` в `config.json` обработка запрещена намеренно (D23).
- Нумерация файлов — по имени, натуральная сортировка. Порядок съёмки не восстанавливаем.
- Папка архива создаётся как `ИСХ`, существующая (`Исх`) не переименовывается.
- Папка считается обработанной, если число файлов `*рентгенограмма*.jpg/.jpeg` равно числу TIFF.
- Разделитель в имени файла — **пробел**: `Рентгенограмма N.jpeg`, `ИСХ\Рентгенограмма N.tif` (D16, было подчёркивание). Если файл в папке один — без номера, `Рентгенограмма.jpeg`/`.tif` (D17). Признак «обработано» — по вхождению слова, поэтому папки, уже обработанные старой сборкой (с подчёркиванием или с номером у одного файла), по-прежнему опознаются как готовые.
- libvips **нельзя обновлять** без повторной проверки импортов: новые сборки не работают на Windows 7 (`BUILD.md`).
- Коммиты и push — только по явной просьбе пользователя.
