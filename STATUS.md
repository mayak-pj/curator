Важная оговорка: на Mac нет ttk-темы `vista`, поэтому светлая тема здесь тоже рисуется через `clam` (ту же, что и тёмная на Windows) — по этому запуску можно судить о раскладке и о тёмной теме (там и там `clam`), но не о точном виде светлой темы на Windows (там нативный `vista`-хром). Автоматические скриншоты окна с этой стороны ненадёжны — дважды подряд вместо окна программы в кадр попадало постороннее содержимое экрана (скриншоты в обоих случаях сразу удалены), поэтому визуальная проверка — на пользователе: он смотрит сам и говорит, что видит. ## Договорённости, которые легко забыть

- Репозиторий остаётся **приватным**; папка `my_reports/` в git не попадает.
- Имя `tifjpg` — для всего нового: пакет, exe, архивы.
- Нумерация файлов — по имени, натуральная сортировка. Порядок съёмки не восстанавливаем.
- Папка архива создаётся как `ИСХ`, существующая (`Исх`) не переименовывается.
- Папка считается обработанной, если число файлов `*рентгенограмма*.jpg/.jpeg` равно числу TIFF.
- Разделитель в имени файла — **пробел**: `Рентгенограмма N.jpeg`, `ИСХ\Рентгенограмма N.tif` (D16, было подчёркивание). Если файл в папке один — без номера, `Рентгенограмма.jpeg`/`.tif` (D17). Признак «обработано» — по вхождению слова, поэтому папки, уже обработанные старой сборкой (с подчёркиванием или с номером у одного файла), по-прежнему опознаются как готовые.
- libvips **нельзя обновлять** без повторной проверки импортов: новые сборки не работают на Windows 7 (`BUILD.md`).
- Коммиты и push — только по явной просьбе пользователя.
